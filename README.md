# Hotel Management System

A console-based Hotel Management System developed using C++.

## Features
- Room Booking
- View Available Rooms
- Customer Details
- Bill Generation
- File Handling

## Technologies Used
- C++
- Structures
- Vectors
- File Handling
- STL

## How to Run

Compile:
g++ main.cpp -o hotel

Run:
.\hotel.exe

## Project Description
This project helps manage hotel room bookings, customer information, room availability and billing through a menu-driven interface.
